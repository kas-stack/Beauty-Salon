# Сайт онлайн-записи для салонов красоты, барбершопов, студий ногтей и ресниц

Универсальный демо-сайт: переключатель ниши меняет дизайн, услуги, цены, мастеров и отзывы.

## Файлы
- `index.html` — структура страницы
- `style.css` — дизайн, цвета ниш (переменные `--a`, `--bg`), тёмная тема, адаптив
- `script.js` — данные (объект `D`), запись клиентов, панель мастера

## Запуск
Откройте `index.html` в браузере.

## Публикация (GitHub Pages)
Settings → Pages → Branch: `main`, папка `/ (root)` → Save.

## Под своего клиента
Измените объект `D` в `script.js` (название, услуги, цены, мастера) и контакты в футере `index.html`.

## Важно
Записи пока хранятся в `localStorage` браузера (демо). Для боевой версии подключите базу (например Supabase).
